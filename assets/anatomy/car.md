# 房車/跑車車體 組件圖譜
> 適用範圍：四門/兩門房車、掀背車、跑車類車體殼體。SUV/巴士/貨車比例改用 `proportions_lib.car_proportions(length, category=...)`（見下方），組件清單原則相通。
> 不含底盤懸吊/引擎機構/內裝座艙——那些屬於 `examples/car.md`。

## 比例計算機（先算尺寸，再對照下方組件清單）
```python
import proportions_lib as PR
p = PR.car_proportions(length=4.7, category="sedan")  # sedan/suv/bus/truck
# p: width/height/wheelbase/front_overhang/rear_overhang/wheel_diameter/wheel_width/
#    door_front_w/door_rear_w/grille_w/grille_h/plate_w/plate_h/headlight_w/headlight_h/
#    turn_signal_w/turn_signal_h/exhaust_d/ground_clearance/doors
```
`door_front_w == door_rear_w`（四門均分軸距）；任一值不合適直接 `PR.car_proportions(4.7, "sedan", wheel_diameter=0.68)` 覆寫。

## 座標公約
觀眾側 = -Y（車頭朝觀眾，§12）。「左/右」一律指**觀眾視角**（駕駛座視角左右相反，描述門把/後視鏡位置先講清楚是哪一種）。

## 六面組件清單

### 正面（-Y，車頭）
| 組件 | 位置（觀眾視角） | 典型尺寸 | 功能語義/朝向 | 細節要求 |
|---|---|---|---|---|
| 頭燈 ×2 | 水平居中兩側，跟保險桿上緣齊平或略高 | `headlight_w/headlight_h` | 照明+品牌識別，跟尾燈是同一套設計語言（造型/分割線呼應） | 玻璃罩用 `mat_lib.make_glass`/`make_coated_glass`，內部可加 `make_emissive` 小面積暖光模擬燈絲反光 |
| 前方向燈 ×2 | 頭燈外側（車寬方向更靠外），或整合進頭燈總成一角 | `turn_signal_w/turn_signal_h`（明顯小於頭燈） | 轉向指示，橘/琥珀色 | 獨立於頭燈的小色塊/小燈殼，`make_emissive` 橘色——常被遺漏的必要件，頭燈存在不代表方向燈存在 |
| 前車牌 | 前保險桿中央 | `plate_w/plate_h` | 車牌，字用 `detail_lib.make_text()` | 比例照計算機給值，不要憑感覺拉一塊矩形 |
| 進氣格柵 | 車頭正中央 | `grille_w/grille_h` | 引擎散熱進風口，常見廠徽/車標位置 | 密集橫向/網狀細條表現通風感，不是純色平面貼一塊黑色了事——MUST 存在（散熱是真實車輛必要功能），不是可省略的裝飾 |
| 前保險桿 | 車頭下緣，全寬 | 貫穿車頭寬度 | 低速碰撞緩衝結構，材質常跟車身分色（黑色塑膠或跟車身同色烤漆） | 下緣常有進氣口/霧燈開口，真的要挖就用 `cut_hole`/`carve_depression`，不要平面貼黑色矩形充數 |
| 引擎蓋 | 頭燈上方、擋風玻璃下方的頂面 | 車寬 x 車長約 15-20% | 覆蓋引擎室的可掀蓋板，表面常有微幅隆起/character line 呼應車身腰線 | 不需要做出可掀開的鉸鏈機構，但**表面至少要刻一條沿邊緣的分模線**（縫隙感，見下方「最低限度表現原則」） |
| 擋風玻璃 | 引擎蓋後方，傾斜面 | 車頭曲率延伸 | 大傾角玻璃，跟車頂連續過渡 | 用 `shape_lib.cut_window()`（薄殼曲面挖窗），不要獨立物件拼接（§13.10 規則 7 船帆事故） |
| 雨刷 ×1-2 | 擋風玻璃下緣 | 玻璃寬度的 60-80% 長條 | 靜止狀態貼在玻璃下緣 | 小型細節件，`add_box`/`add_cyl` 即可，別遺漏——沒有雨刷的擋風玻璃是常見的「漏掉小配件」破綻 |
| 前輪拱 ×2 | 車頭左右兩側下方 | 對應輪胎直徑+餘量 | 容納前輪轉向行程的凹陷空間 | 車體上必須真的挖空（`cut_hole`/`carve_depression`），見「成對組件」跟下方常見錯誤 #1 |
| 側後視鏡 ×2 | A 柱/前門交界處，車身外側 | 小型突出物，寬 0.15-0.25m | 駕駛視野輔助，鏡面朝車後方向 | 從正面/三分之四視角就看得到，不是只有側面才需要 |

### 背面（+Y，車尾）
| 組件 | 位置 | 典型尺寸 | 功能語義 | 細節要求 |
|---|---|---|---|---|
| 尾燈 ×2 | 對應頭燈位置，車尾兩側 | 跟頭燈同一套語言 | 煞車/尾燈，紅色為主 | `make_emissive` 紅色 |
| 後方向燈 ×2 | 尾燈外側或整合進尾燈總成一角 | `turn_signal_w/turn_signal_h` | 轉向指示，橘/琥珀色 | 同前方向燈，獨立色塊，不是尾燈一片紅色了事 |
| 後保險桿 | 車尾下緣，全寬 | 貫穿車尾寬度 | 同前保桿邏輯 | 常整合排氣管開口 |
| 後擋風玻璃 | 車頂後緣延伸 | 依車型（掀背/房車傾角不同） | 房車通常比前擋更直立 | 同樣用 `cut_window()` |
| 尾門/後行李廂蓋 | 後擋風玻璃下方到後保桿之間 | 車尾主要面板 | 可開闔的行李廂/尾門，常有車型銘牌文字 | 不需要可開闔機構，但**至少刻出邊緣分模線**；銘牌文字用 `detail_lib.make_text()` |
| 排氣管 ×1-2 | 後保桿下緣兩側或居中 | `exhaust_d`，微凸出保桿 | 排放廢氣，常鍍鉻或霧面金屬 | `add_cyl` + `cut_hole` 挖出管口深度感，不要純色實心圓柱看起來像塞住的——MUST 存在，不是選配 |
| 後輪拱 ×2 | 車尾左右兩側下方 | 同前輪拱 | 跟前輪拱成對，共 4 個輪拱缺一不可 | 同上，必須真的挖空 |
| 後車牌 | 後保桿上方或尾門下緣 | `plate_w/plate_h` | 車牌+凹槽/掛架 | 跟前車牌同尺寸 |
| 高位煞車燈（選用） | 尾廂蓋上緣或後擋風玻璃內側 | 小型長條 | 第三煞車燈，跑車/掀背車常見 | 選用，非必要 |

### 頂面（+Z）
| 組件 | 位置 | 典型尺寸 | 功能語義 | 細節要求 |
|---|---|---|---|---|
| 車頂 | 整個頂面 | 全車長寬的中段曲面 | 跟前後擋風玻璃連續過渡的單一曲面 | 這是 §13.10 規則 7 最容易出事的地方——車頂→玻璃艙→後窗必須是同一片連續 mesh 塑形，不是分開建的平板拼接 |
| 鯊魚鰭天線 | 車頂後段中央偏一側 | 小型三角鰭狀凸起 | 現代車常見的整合式天線 | 選用但很容易被忽略的小細節，加了會明顯提升真實感 |
| 天窗（選用） | 車頂前段 | 依車型 | 玻璃嵌板，可用不同材質+微凹陷表現 | 選用 |
| 車頂行李架（選用） | 車頂左右兩側縱向 | 兩條縱桿 | SUV/旅行車常見，房車/跑車通常沒有 | 依車型判斷要不要加，房車/跑車類主體通常省略 |

### 底面（-Z）
| 組件 | 位置 | 典型尺寸 | 功能語義 | 細節要求 |
|---|---|---|---|---|
| 底盤護板 | 整個底面 | 全車底 | 平整空氣力學護板 | 展示照通常拍不到，除非任務明確要求仰視角，一般可省略細節，維持簡單平面即可 |
| 排氣管路由 | 底盤後半段 | 細管線 | 從引擎連到尾管 | 同上，非必要 |

### 左側面（-X）/ 右側面（+X，互為鏡像，成對存在）
| 組件 | 位置 | 典型尺寸 | 功能語義 | 細節要求 |
|---|---|---|---|---|
| 車門 ×2 或 ×4（依門數） | 前後輪拱之間 | `door_front_w`/`door_rear_w`（四門應等寬） | 供乘員上下車 | 不需要可開闔機構，但必須刻出門縫分模線（見下方「最低限度表現原則」）——沒有分模線的側面是一整塊沒分件的實心量體 |
| 門把手（每扇門各一個） | 每扇車門的中後段外側 | 小型突出/內凹件 | 開門把手 | 每一扇門都要有，不是象徵性做一個——四門車要 4 個 |
| 車窗（對應門數） | 每扇門上方 | 對應車門寬度 | 可升降窗（不需要做出升降機構，做成固定嵌入玻璃即可） | 用 `cut_window()`，跟擋風玻璃同一套技法，繼承車身曲率 |
| A/B/C 柱 | 車窗之間的分隔柱 | 依門數決定有幾根 | 結構支撐+車窗分隔 | 車身本體的一部分，不是獨立物件，靠 `cut_window()` 挖窗時自然留下的實面就是柱體 |
| 側裙 | 車門下緣、輪拱之間 | 沿車身下緣一條 | 常跟車身分色/分材質的下緣飾板 | 選用，跑車類常見，房車類可省略 |
| 輪拱 ×4（前 2 後 2） | 四個車輪對應位置 | `wheel_diameter` + 餘量 | 容納車輪+轉向/避震行程的凹陷空間 | **本圖譜最重要一條**：四個位置必須真的挖空（`cut_hole`/`carve_depression`），不挖輪胎裝上去會穿模，見常見錯誤 #1 |
| 車輪 ×4 | 四個輪拱內 | `wheel_diameter`/`wheel_width` | 輪圈+輪胎組合，各自獨立物件；**「輪圈+輪胎」只是最外層兩個量體，不是輪子的完整組件清單**——輪圈本身還有下面這些真實存在的次組件，缺了會讓輪子看起來像一片光禿禿的碟子 | 輪圈直徑常見誤判偏小——照計算機給值，不要憑感覺縮小 |
| ├ 輪輻/輪輞造型（spokes） | 輪圈正面 | 依款式 5-10 輻 | 真實輪圈幾乎不是一片實心圓盤，是輻條/輪輞鏤空造型（運動輻條/多輻/渦輪扇形款依風格自選） | `gear_wheel()`（§0.5，本來是給齒輪用，`root_ratio`/`teeth` 調大調少一樣能生出輻條式鏤空輪圈剪影）或 `shape_lib.radial_dish()` 起手，鏤空範圍布林挖空 |
| ├ 中心蓋（center cap） | 輪圈正中心 | 直徑約輪圈 15-25% | 遮蓋輪軸+常印品牌 logo | `add_cyl()`+`detail_lib.make_text()`，缺了中心會露出結構軸心，觀感未完工 |
| ├ 氣嘴/氣嘴蓋（valve stem cap） | 輪圈內緣，非置中，沿圓周任一角度 | 極小 | 打氣閥門，現實中一定存在，是很容易被忽略的小配件 | `add_cyl()` 一根細短圓柱沿輪圈內緣徑向凸出即可，不需要複雜幾何，但**缺席是缺件**，見常見錯誤 #6 |
| ├ 煞車卡鉗（brake caliper） | 輪圈鏤空處後方，透過輻條縫隙可見 | 依款式，常見紅/黃/黑烤漆 | 高性能/運動款车常見塗裝卡鉗刻意露出，一般款也至少該有卡鉗量體填補鏤空後方的空洞感 | `add_box()`/`add_cyl()` 簡化量體即可，放在輪轂軸心跟輻條鏤空範圍之間，沒有的話透過輻條縫隙會看到輪拱內部的空洞，穿幫 |
| ├ 螺帽/螺栓（lug nuts） | 中心蓋外緣一圈 | 4-6 顆，小型 | 固定輪圈的螺栓，真實輪圈上一定看得到 | `instance()` 陣列複製一顆小型六角/圓錐螺帽母版 |
| 油箱蓋 | 左側或右側車尾附近（僅一側，不成對） | 小型圓形/方形嵌板 | 加油口蓋 | **刻意不成對的例外**——只在一側，加在另一側是錯誤，不要因為「其他部件都成對」的慣性誤判油箱蓋也要兩邊都加 |
| 腰線/character line | 沿車身側面貫穿前後的水平凸稜或凹稜 | 全車長 | 純造型語彙，連接頭燈到尾燈的視覺連續線條 | 用 `shape_lib.loop_cut()`+`move_verts()` 在殼體上做出真正的凸起/凹陷稜線，不是貼一條深色裝飾條了事——這條線是車身「有沒有設計感」的關鍵，純色平面車身會顯得廉價 |

## 成對組件（缺一即錯）
| 前端件 | 後端件/對應件 | 配對規則 |
|---|---|---|
| 頭燈 | 尾燈 | 同一套設計語言（造型輪廓/分割線呼應），不是隨便兩種不相干的燈型 |
| 前輪拱（左） | 前輪拱（右）+ 後輪拱（左）+ 後輪拱（右） | 四個輪拱都要有，都要真的挖空——見常見錯誤 #1 |
| 左後視鏡 | 右後視鏡 | 同尺寸同造型，鏡像對稱 |
| 車門（每一扇） | 對應的門把手 | 有幾扇門就有幾個門把手，不能只做一個當代表 |
| 車門（每一扇） | 對應的車窗 | 每扇門上方都該有對應窗戶（掀背車後門/跑車兩門例外需依實際車型判斷） |

**刻意不成對的例外**：油箱蓋只在一側；駕駛座/副駕駛座在方向盤配置不同的地區（左駕/右駕）左右不對稱，但外觀殼體本身通常仍是對稱的，不對稱的是內裝，不影響本圖譜範圍。

## 最低限度表現原則（通用規則，不只車輛適用）

判準：這個部件不存在，現實中這個物件還能不能正常運作？不能（車沒門把→上不了車）就是 MUST，即使不用做可動機構，至少刻分模線+做出部件本身的小型幾何。能（車頂行李架）就是 OPTIONAL，依車型判斷。寫進 §11 元件表的「小元件」欄，Stage A 就想過，不要等 Stage C 使用者發現才補。

## 常見錯誤（實戰回填區）

| # | 錯誤 | 判讀方式 | 修正 |
|---|---|---|---|
| 1 | 車體殼體沒有在四個輪拱位置真的挖空，車輪直接懸空貼在殼體外側或穿插進殼體內部 | 渲染圖近看/側面角度看得出輪胎跟車身邊緣重疊穿模，或輪子懸空跟車身之間有不自然的縫隙 | 四個輪拱用 `cut_hole()`（貫穿殼體）或 `carve_depression()`（凹陷造型視覺）真的挖出容納輪胎的空間，不是輪子直接懸浮在原本沒有開口的殼體旁邊 |
| 2 | 側面車身完全是一整片連續烤漆，看不出任何門的分界、也沒有門把 | 使用者一眼看出「這台車沒有門」，車身像一整塊沒有分件的玩具 | 至少刻出門框分模線+每扇門一個門把手，見上方「最低限度表現原則」 |
| 3 | 玻璃艙（擋風玻璃+車頂+後窗）用多個獨立物件各自拼接，不是連續殼體挖窗 | 渲染出來像插了幾片船帆，曲率不連續（§13.10 規則 7 同款事故） | 一律用 `shape_lib.cut_window()` 在連續殼體上挖窗，見 `examples/car.md` 階段三 |
| 4 | 側面車身完全平整，沒有任何腰線/character line | 車身顯得扁平廉價，缺乏工業設計感 | 用 `loop_cut()`+`move_verts()` 做出真正的凸起/凹陷稜線，不是貼裝飾條 |
| 5 | 前後門寬不等、輪圈偏小、缺方向燈/排氣管/進氣格柵、車牌比例亂猜 | 港式計程車實測案例一次全中 | 一律用 `proportions_lib.car_proportions()` 起算，不要憑感覺填數字 |
| 6 | 輪圈建成一片實心圓盤或只有最外層「輪圈+輪胎」兩個量體，沒有輻條鏤空、中心蓋、氣嘴、卡鉗、螺帽這些次組件 | 特寫看輪圈像一片光禿禿的碟子或塑膠玩具輪，沒有真實輪圈該有的鏤空立體感跟金屬小配件細節 | 見上方「車輪」列的次組件清單，五個次組件（輻條/中心蓋/氣嘴/卡鉗/螺帽）逐項補齊，不是只做外層兩個量體就收工 |
