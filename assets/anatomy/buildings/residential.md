# 住宅大樓 外觀組件圖譜
> 適用範圍：集合住宅/公寓大樓外觀量體（不含室內格局、結構工程細節）
> 依據來源：已查證的公開研究（陽台設計指南、高層冷氣機罩散熱研究、樓層高度比較）。

## 一樓（MUST）

| 組件 | 說明 | 對應工具 |
|---|---|---|
| 入口大堂 | 樓層高度明顯高於標準層（1.4-1.6 倍常見） | `floor_specs[0].height` 拉高 |
| 入口雨遮/迎賓道 | 懸挑板+支柱，遮蔽入口到路緣的動線 | `make_entrance_canopy()` |
| 大面積玻璃立面 | 大堂通透感，`window_ratio` 遠高於標準層 | `floor_specs[0].window_ratio` = 0.75-0.85 |
| 信箱區 | 通常在大堂內部，外觀量體不需要單獨建模 | （室內範疇，不影響外觀） |
| 玻璃後方別留空（見 `_INDEX.md`） | 大堂/標準層玻璃量大時，中空樓層背後渲染出來接近純黑方塊，材質調不回來——缺的是幾何 | `building_lib.add_interior_blockout()`，粗模柱網+桌椅即可，不需要每層都做 |

**選用**：一樓零售店面（沿街店鋪）——若任務要求商住混合，`floor_specs[0]`
可以再拆更高的 `window_ratio`（0.85+）模擬展示櫥窗，本圖譜不強制。

**選用**：**基座/裙樓量體**——大型集合住宅常見「低樓層（店面/公共設施/停車）平面
明顯大於上方住宅標準層」的基座＋塔樓剖面，做法是 `assemble_building()` 呼叫兩次
（裙樓 `base_z=0`、住宅塔樓 `base_z=裙樓總高`），見 `_INDEX.md` 專節；依任務尺度
（單棟小宅 vs 大型社區）決定要不要用，本圖譜不強制。

## 標準層（MUST，重複到頂層前一層）

| 組件 | 說明 | 對應工具 |
|---|---|---|
| 落地窗/大面積開窗 | 住宅 WWR（窗牆比）查證典型範圍 **20-30%**——注意這是**低於**辦公大樓的比例，不要套用辦公大樓數值 | `window_ratio` 0.5-0.6（本函式的 window_ratio 是「單格窗占格子比例」，不是整片牆的 WWR，數值上不直接等同查證的 WWR 百分比，但方向一致：住宅這格比例應明顯低於辦公） |
| 陽台 | 三種真實類型：**懸挑式**（projecting，外露最明顯，本圖譜配套函式做這種）、**退縮式**（recessed，內凹進立面，任何高度都適用包含超高層）、**Juliet**（無地板懸挑，只有欄杆，等於落地窗+一道欄杆） | 懸挑式：`add_balcony()`；退縮式：`assemble_building()` 該格 `recess` 加大即可近似；Juliet：不需要額外函式 |
| 陽台覆蓋率 + 分戶側牆（立面「凹凸美感」的主要來源） | 只在少數開間放懸挑陽台、中段留大片平牆，立面會扁平、陽台像貼上去的裝飾。真實案例是**整面寬度幾乎每個開間都有陽台，且陽台兩端都有一道分戶側牆**（垂直於立面、跟陽台同深，隔開相鄰單位），斜側光下每道側牆都會投下陰影。把覆蓋率從 2/8 開間提高到接近滿版（4 道陽台涵蓋 8 開間寬度）並加上側牆後，立面明顯從扁平變成有連續進退層次——這不是材質或燈光能補的，是量體本身的問題 | `add_balcony(..., cheek_mat=側牆材質)`（`cheek_mat`/`cheek_thickness` 參數：給值即自動在陽台兩端加側牆，回傳多一個 `[cheek_a, cheek_b]`）；陽台密度抓「覆蓋該面牆寬度的大部分開間」而不是「幾個裝飾性角落陽台」，每道陽台盡量都帶側牆，不要只做欄杆 |
| 冷氣室外機 | **不要用實心箱子**——查證確認密封罩導致散熱效率最多降 34%、耗電上升，真實作法是外露或用開放式百葉罩 | `add_ac_units(louver=True)` |
| 樓層高度 | 查證典型範圍 **2.7-3.0m**（高端可到 3.3m）——明顯低於辦公大樓的 3.6-4.3m，不要混用 | `floor_specs[i].height` |
| 四面採光 | `assemble_building()` 本身就對四面牆套用同一組 `window_ratio`，**預設本來就四面都有窗**，不需要額外呼叫什麼——但如果任務中途對其中一面另外覆寫材質/挖窗（例如只想讓正面立面更講究），要記得這個覆寫不會自動同步到另外三面，收工前建議跑一次材質面數統計確認四面玻璃比例沒有被意外改成只剩一面（直接開 `.blend` 數面數比純看渲染圖準確——單一鏡頭角度只拍得到 1-2 面，肉眼看不出另外兩面有沒有跟著做） | 收工前 `execute_blender_code`/probe 腳本按 x/y 座標分組數 `material_index`，四面玻璃面數應接近一致 |
| 陽台/服務陽台分布 ≥2 面 | 真實住宅大樓的陽台通常分布在至少兩個朝向——不同房間格局各自需要對外陽台，不是所有房間的陽台都朝同一面；只做鏡頭朝向那一面在畫面上「看起來夠了」，但那是取景習慣造成的偏差，不是真實建築的樣子 | `add_balcony()`/`add_ac_units()`（`wall` 參數可選 `front`/`back`/`left`/`right`）呼叫時至少選兩個不同的 `wall` 值，同一批附加構件不要全部堆在同一面 |
| 隨機「已入住」暖光窗 | 全樓窗戶用同一種玻璃材質＝一眼看出是空樓模型；真實住宅大樓會有部分住戶窗戶呈現不同色調（拉簾/開燈），約 10-15% 窗戶隨機換暖色效果明顯更真實——**但這個技巧只有在偏暗的環境光下才有效**（`studio`/日光級 preset 下 `make_emissive()` 純自發光材質 strength 從 0.9 調到 7.0 都會被 AgX 壓成近乎純白，看不出暖色；換到 `night` preset/暗環境才清楚呈現暖色發光，見 `mat_lib.make_emissive()` docstring） | **夜景/`night` preset**：`random.random() < .13` 把約一成窗戶材質換成 `mat_lib.make_emissive()` 暖色即可，效果符合預期。**日光/`studio` preset**：純 emissive 卡片效果差，改用 Transmission=1.0 的暖色玻璃（Base Color 直接給飽和暖色如 `(0.55,0.40,0.22)`，不是靠 Emission 撐色相）+ Emission strength 只給 1.0-1.5 當輕微加成——只能做出「窗簾是暖色」的效果，做不出「真的在發光」的效果；如果日光場景做這個細節的視覺回報明顯低於預期，也可以直接跳過，把心力放在別的細節上 |

## 中段變化（OPTIONAL，依任務目標選其一，不要兩者都硬加）

- **純視覺分段**（腰帶樓層）：某幾層換一種牆面材質/窗比例，做出立面節奏感——
  純粹風格化選擇，`_INDEX.md` 已說明這不是業界普遍做法，是可用但非必要的手法。
- **機能分段**（機電/避難層，僅超高層適用）：每 15-20 層插入一個樓層高度明顯
  變高（3-7.6m）、`window_ratio` 大幅降低甚至接近 0（機電層外觀通常是實牆/
  百葉，不是玻璃窗）的樓層——只有樓層數夠多（40+ 層）才需要考慮，中低層住宅
  大樓不需要這個元素。

## 頂層/屋頂（MUST）

| 組件 | 說明 | 對應工具 |
|---|---|---|
| 機電penthouse | 電梯機房+設備間，近乎所有住宅大樓都有 | `floor_specs` 最後一項用較低 `window_ratio`（0.1-0.2）+較矮 `height` 模擬 |
| 女兒牆/欄杆（parapet） | **真實構造是「實心矮牆+頂部收邊」，不是單純把頂層窗比例調到 0 就等於做出來了**——後者只是近似出「頂層沒有窗」的外觀，沒有真的建出突出屋頂平面的矮牆量體。常見高度 900-1200mm（對應各地安全法規的最低護欄高度）。頂部常見兩種收邊：**實心壓頂**（coping，矮牆本身到頂，只在最上緣做一圈材質/色差不同的收邊條，常見於磚石/混凝土立面）；**矮牆+金屬/玻璃欄杆疊加**（矮牆只到腰部，上方再加一段金屬扶手或玻璃嵌板到達安全高度，常見於現代玻璃帷幕/高端住宅，視覺上更輕盈）——兩種選一種，依整棟建築的立面語言決定（磚石/厚重立面配實心壓頂，玻璃帷幕配欄杆疊加） | 矮牆本體：沿屋頂邊緣一圈 `add_box()`（或曲面建築用 `flat_ring()`），內縮於屋頂邊界一小段厚度（不要跟外牆齊平，矮牆比下方樓層外牆略內縮是常見真實做法）；壓頂收邊：矮牆頂面另开一條窄材質帶（`make_metal()`/`make_stone()` 依立面語言）；欄杆疊加款：`shape_lib.curve_tube()` 沿矮牆頂緣串出扶手橫桿，配直立支柱（`add_cyl()` 等距陣列），玻璃嵌板用 `make_glass()`（**別忘了住宅大樓陽台事故的教訓——tint 選得比背景天空明顯更深，不要選跟天色接近的淺藍，見上方常見錯誤模式#3**） |
| 水塔 | 部分地區/年代常見外露量體 | `build_template.add_box()`/`add_cyl()` 手動加一個小量體即可，不需要專屬工具 |
| 避雷針＋航空障礙燈 | **高層住宅（約 20 層以上／明顯高於周邊天際線）MUST**：避雷針是結構必備構件，航空障礙燈是民航法規要求（夜間可見紅燈）——中低層住宅不需要，不要無條件套用 | `building_lib.make_lightning_rod()`，立於屋頂最高點，見 `_INDEX.md` 專節（含日光下的讀色陷阱） |

## 材質基調（依 mat_lib.py 既有 factory 選用，非新工具）

住宅偏暖、偏人性尺度——`mat_lib.make_paint()`（淺色系烤漆/塗料外牆）、
`make_stone()`（一樓常見石材基座，做出「一樓比標準層更堅實」的視覺分量）、
窗戶玻璃用 **`make_glass()`**（暖色調/中間色調 tint，不要用辦公大樓那種冷色高
反光鏡面玻璃，那是 flagship_hq/office 的語彙不是住宅的）——**不要用
`make_coated_glass()`**（這支函式是模擬鏡頭鍍膜的「高吸收+高反射」材質，預設 tint 逼近全黑，套在整棟大樓窗戶上每格都是不透光的黑方塊；對照組 `make_glass()` 中間色調 tint 能清楚透出背景，見 `mat_lib.make_coated_glass()` docstring）。實測可用 tint 範圍：
`(0.14-0.20, 0.19-0.25, 0.22-0.28)` 偏藍綠中灰調，`specular` 0.4-0.55、
`roughness` 0.05-0.08。

## 常見錯誤（實戰回填區）

| # | 錯誤 | 判讀方式 | 修正 |
|---|---|---|---|
| 1 | 住宅立面套用辦公大樓等級的 window_ratio/樓層高 | 立面看起來像玻璃幕牆辦公樓，不像住宅 | window_ratio 壓低到 0.5-0.6、樓層高壓到 2.7-3.0m 範圍 |
| 2 | 冷氣機正面朝馬路/正立面外露且無任何遮蔽 | 視覺雜亂，且跟本圖譜的 louver 建議衝突 | `add_ac_units(louver=True)`，或把機組安排在陽台內側/服務陽台 |
| 3 | `add_balcony()` 的 `railing_mat` 用接近天空色調的淺藍/白玻璃（例如 tint 跟 `outdoor_golden` 天空色高度接近），且欄杆本身厚度只有 2cm（`_mesh_box` 內建值，非參數） | 幾何跟材質都正確設定（實測直接開 `.blend` 查證：物件真的存在、尺寸 1.05m 高、有指定材質），但渲染出來完全看不出欄杆——極薄的高透光玻璃疊上跟背景幾乎同色的 tint，等於自己把自己「偽裝」進天空裡（欄杆的幾何一直都在，是材質選色讓它隱形，不是幾何缺失）。同一根因也會讓 `assemble_building()` 的窗戶玻璃在天空背景前顯得「整棟都透明看不到玻璃」——玻璃 tint 跟牆面材質的 clearcoat 反光在強逆光/黃金時刻天空下對比不足，兩者在畫面上糊成同一片反光色塊 | 欄杆/薄玻璃類構件的 tint 刻意選得比背景天空明顯更深或更飽和（不要為了「通透感」選跟天色相近的淺藍），必要時把 `roughness` 調高一點犧牲一些鏡面反射換取可辨識度；牆面材質的 `clearcoat`（`make_paint()` 參數）不需要為了「有質感」給到接近滿值，太高的清漆反光會讓不透明牆面在強光下也閃出跟玻璃相近的天空反光，反而讓玻璃/牆面的視覺分野消失 |
| 4 | 窗戶玻璃用 `make_coated_glass()`、已入住暖光窗用純 `make_emissive()`，且整棟渲染用日光級 `studio` preset（實測發現的真實 bug） | 渲染出來整棟樓的窗戶不是近乎全黑的方塊（未入住窗）就是死白色方塊（已入住窗），沒有任何玻璃該有的通透層次/顏色深度，跟真實玻璃該有的藍綠色調差距明顯——用同一背景色前的對照渲染驗證：`make_coated_glass()` 預設 tint 完全遮蔽背景，`make_glass()` 中間色調 tint 能清楚透出背景色；`make_emissive()` 在 `studio` preset 下不管 strength 從 0.9 測到 7.0 全部被 AgX 壓成近乎純白，看不出暖色 | 未入住窗換 `make_glass()`（中間色調 tint，見上方材質基調段落的具體數值範圍）；已入住暖光窗如果場景是日光級 preset，改用 Transmission=1.0 的暖色玻璃（Base Color 直接給飽和暖色）+ Emission strength 只給 1.0-1.5 當輕微加成，不要指望日光場景做出「真的在發光」的效果，那個效果留給夜景場景（`night` preset/`auto_night_fill()`） |
