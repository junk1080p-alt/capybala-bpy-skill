## 使用流程（強制）
1. Stage A：命中觸發詞 → read_file_native（或你的 agent 平台上等價的讀檔工具）讀風格卡 → 設計簡報的「比例規劃段」「材質段」直接引用卡片數值；「色票段」以卡片色票為**起點**（使用者指定色/參考圖優先）。
2. 元件表「組合方式」段引用卡片★形式語言，保持設計語言一致（☆Prompt 模板欄選填，只在需要 2D 概念示意圖時用）。
3. Stage B：materials.py 照 ★材質映射表寫；config.PROPORTIONS 照 ★形式語言寫；細節照 ★細節特徵。
4. 動工前跑 ★落地 checklist；SCENE_STATE 增報 style_card 引用名（色彩只求可追溯，**不做占比審計**）。
5. 卡片內容與實戰結果衝突 → 回填卡片（單一真相源，同 skill asset 修正規則 §9.3.5）。
