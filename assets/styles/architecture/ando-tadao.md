# 安藤忠雄 Tadao Ando（建築）
觸發詞：安藤忠雄、清水混凝土、光之教堂、混凝土詩學
適用年代：1976-now（住吉長屋 1976 / 光之教堂 1989 / 地中美術館 2004）

## ★ 一句話定位
模板拼縫清晰可讀的清水混凝土 + 幾何光縫，材料即裝飾、光影即傢俱。

## ★ 理念
- 「建築是光與混凝土的詩」：光以幾何縫隙進入，隨時間移動 [src: 安藤忠雄公開演講語境]
- 材料誠實：混凝土不貼不塗，模板痕跡（對拉螺栓孔）保留為表面節奏
- 封閉外殼 vs 豐富內庭：外觀極簡，內部空間靠庭院/光縫制造戲劇性
- 幾何原型：圓/方/三角的純粹組合（真言宗本福寺水御堂：蓮池下的圓形混凝土空間）

## ★ 形式語言
- **比例系統（§15.0）：黃金比例×費波那契為主**——整體量體長寬取 1:1.618；模板模數（1800×900mm）是細節層級的簡單整數比/模矩制，兩者不衝突（大尺度用黃金比例、施工紋理節奏用模矩）。
- 比例：方體為主，長寬 1:1.618；開口是「縫」不是「窗」（光縫寬 = 墻高×0.01-0.03）
- 模板模數：1800×900mm 模板分格，每格四角對拉螺栓孔（⌀20mm 圓孔）——**這是安藤識別度的核心**
- 十字光縫：光之教堂式——墻面十字縫寬 ≈ 墻高×0.02
- 圓：純幾何圓（樓梯塔/柱），與方體相切或相交
- 無裝飾線：唯一表面資訊 = 模板拼縫 + 螺栓孔

## ★ 細節特徵（detail_lib / geometry）
- 模板拼縫：ridge_lines 變體——凹槽寬 6mm 深 2mm，1800×900 網格（seam 材質給陰面色）
- 對拉螺栓孔：grip_strip 變體——每模板格四角 ⌀20mm 圓窩（凹，非凸；mat 陰面色）
- 光縫：墻體布爾差集或兩塊墻留縫 + 縫內 emissive 面
- 樓梯：懸挑踏步嵌入混凝土墻，無欄杆或單根金屬桿

## ★ 落地 checklist
- [ ] 混凝土占比 ≥70%，零塗裝色
- [ ] 模板拼縫網格可見（至少一個主立面）+ 螺栓孔點陣
- [ ] 至少一處光縫/十字縫/高窗縫，emissive 或強方向光穿縫
- [ ] 光影對比強：night preset 不可用，用 outdoor_golden 或 studio 單側強光

## ☆ 燈光/渲染
單側強方向光（Sun 2.0-2.8）+ 低 sky_strength（0.15-0.25）：混凝土的質感靠側光斜射；光縫場景內部補弱 Fill。AgX look=Neutral（保留暗部混凝土細節）。
